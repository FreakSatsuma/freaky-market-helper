# Freaky Market Helper

A Tampermonkey / Violentmonkey userscript for [Torn](https://www.torn.com) that fills your Item Market and Bazaar listings in one click.

- **Item Market** (Add Items): a Fill button, select box and favourite star on every row, plus Fill All.
- **Bazaar** (Add Items and Manage): the same tools, with an Update button on Manage. Dollar bazaar mode lists everything for $1.
- **Pricing formulas**: cheapest listing, average sale price (`[avg]`), market value (`[market]`) or live bazaar prices (`[bazaar]`, via weav3r.dev), with `min()`/`max()` ranges.
- **Quantity rules**, per-category overrides, a session receipt, and separate settings for the Item Market and the Bazaar.

## Install

Install from [Greasy Fork](https://greasyfork.org/en/scripts/601273-freaky-market-helper) or open the raw file and let your userscript manager install it:
`freaky-market-helper.user.js`
